# Task 1 Report – Personal Portfolio Website

## 1. Task Overview

As part of the **Synent Technologies Web Development Internship**, Task 1 was to develop a **Personal Portfolio Website**.

The purpose of this task was to create a responsive and user-friendly website that presents my personal profile, skills, education, and contact information in a professional way.

## 2. Project Title

**Personal Portfolio Website**

## 3. Objective

The main objectives of this task were:

* To create a professional personal portfolio website.
* To practice HTML5, CSS3, and JavaScript.
* To create a responsive website for different screen sizes.
* To organize personal information in different sections.
* To implement smooth navigation and interactive features.
* To create a clean and user-friendly interface.

## 4. Technologies Used

The following technologies were used to develop this project:

### HTML5

HTML5 was used to create the structure and content of the website.

### CSS3

CSS3 was used for:

* Website styling
* Layout design
* Responsive design
* Colors and typography
* Navigation styling
* Mobile-friendly layout

### JavaScript

JavaScript was used to add interactivity and dynamic functionality to the website.

## 5. Main Features

The website includes the following features:

* Home/Hero section
* About Me section
* Skills section
* Education information
* Contact section
* Contact form
* Smooth navigation
* Responsive navigation menu
* Mobile-friendly layout
* Responsive design

## 6. Methodology

The project was developed using the following steps:

### Step 1 – Planning

First, the main sections and required features of the portfolio website were identified.

### Step 2 – HTML Structure

The basic structure of the website was created using HTML5.

Different sections such as Home, About, Skills, and Contact were added.

### Step 3 – CSS Styling

CSS3 was used to design the website and make it visually attractive.

Responsive styling was also added so that the website can work properly on different screen sizes.

### Step 4 – JavaScript

JavaScript was added to provide interactive functionality such as responsive navigation and other website interactions.

### Step 5 – Testing

The website was tested in the browser to check:

* Navigation
* Layout
* Responsiveness
* Contact section
* Mobile view
* Overall appearance

### Step 6 – Finalization

After testing, the final project files and screenshots were organized for submission to GitHub.
